# 42 Python Piscine 🐍

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python](https://img.shields.io/badge/python-3.x-blue.svg)](https://www.python.org/)

Bem-vindo ao repositório do **42 Python Piscine**! Este projeto é um módulo intensivo de programação em Python oferecido pela 42 School, focado em ensinar os fundamentos da linguagem através de exercícios práticos e desafios.

## 📋 Sobre o Projeto

O Python Piscine é uma imersão completa na programação Python, projetada para desenvolver habilidades essenciais de programação através de uma série de exercícios progressivos. O objetivo é construir uma base sólida em Python, desde conceitos básicos até tópicos mais avançados como programação orientada a objetos.

## 🎯 Objetivos de Aprendizagem

- ✅ Dominar os fundamentos da linguagem Python
- ✅ Desenvolver habilidades de resolução de problemas
- ✅ Compreender programação orientada a objetos
- ✅ Trabalhar com estruturas de dados e algoritmos
- ✅ Aplicar boas práticas de programação (PEP 8)

## 📚 Estrutura do Projeto

O projeto está organizado em módulos (days), cada um focando em aspectos específicos:

### Day 00 - Fundamentos
Introdução ao Python, variáveis, tipos de dados, operadores básicos e I/O

### Day 01 - Estruturas de Controle
Condicionais (if/elif/else), loops (for/while) e funções básicas

### Day 02 - Estruturas de Dados
Listas, tuplas, dicionários e conjuntos (sets)

### Day 03 - Programação Orientada a Objetos
Classes, objetos, métodos, atributos, herança e encapsulamento

### Day 04 - Arquivos e Exceções
Manipulação de arquivos, tratamento de exceções e context managers

## 🚀 Como Começar

### Pré-requisitos

- Python 3.x instalado
- Editor de código (VS Code, PyCharm, vim, etc.)
- Terminal/Console

### Instalação

1. Clone este repositório:
```bash
git clone https://github.com/Andrefcampos/42-PythonPiscine.git
cd 42-PythonPiscine
```

2. Execute os exercícios:
```bash
python3 <nome_do_arquivo>.py
```

## 📖 Avaliação

Os exercícios são avaliados com base em:

- ✓ Correção do código
- ✓ Conformidade com PEP 8
- ✓ Eficiência da solução
- ✓ Tratamento de casos especiais e edge cases

## 📝 Normas de Código

- Todo código deve seguir as diretrizes PEP 8
- Funções devem ter documentação adequada (docstrings)
- Código limpo e legível
- Nomes de variáveis descritivos
