# 42 Python Piscine

## Descrição do Projeto

O **42 Python Piscine** é um módulo intensivo de programação em Python oferecido pela 42 School. Este projeto tem como objetivo introduzir os estudantes aos conceitos fundamentais de programação em Python através de uma série de exercícios práticos e desafios.

## Objetivos

- Aprender os fundamentos da linguagem Python
- Desenvolver habilidades de resolução de problemas
- Compreender conceitos de programação orientada a objetos
- Trabalhar com estruturas de dados e algoritmos
- Desenvolver boas práticas de programação

## Estrutura do Projeto

O projeto está organizado em diferentes módulos (days), cada um focando em aspectos específicos da linguagem Python:

### Day 00 - Fundamentos
- Introdução ao Python
- Variáveis e tipos de dados
- Operadores básicos
- Entrada e saída de dados

### Day 01 - Estruturas de Controle
- Condicionais (if, elif, else)
- Loops (for, while)
- Funções básicas

### Day 02 - Estruturas de Dados
- Listas
- Tuplas
- Dicionários
- Conjuntos (Sets)

### Day 03 - Programação Orientada a Objetos
- Classes e objetos
- Métodos e atributos
- Herança
- Encapsulamento

### Day 04 - Arquivos e Exceções
- Manipulação de arquivos
- Tratamento de exceções
- Context managers

## Requisitos

- Python 3.x
- Editor de código (VS Code, PyCharm, vim, etc.)
- Terminal/Console

## Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/Andrefcampos/42-PythonPiscine.git
cd 42-PythonPiscine
```

2. Execute os exercícios:
```bash
python3 <nome_do_arquivo>.py
```

## Avaliação

Os exercícios são avaliados com base em:
- Correção do código
- Seguimento das normas de código Python (PEP 8)
- Eficiência da solução
- Tratamento de casos especiais

## Normas

- Todo o código deve seguir as diretrizes PEP 8
- Funções devem ter documentação adequada
- O código deve ser limpo e legível
- Variáveis devem ter nomes descritivos
